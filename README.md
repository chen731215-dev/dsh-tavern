# dsh-tavern · DSH 酒馆插件

DeepSeek Harness 的**原生酒馆管理面板**。入口位于 DSH **「设置」→「通用设置」→「酒馆管理（原生）」**（不在侧边栏）。不用 iframe、随 DSH 深浅色换肤、切到其它工作区自动收起。

## ✨ 功能特性

- **会话级多预设隔离**：每个 Harness 会话可独立绑定不同的角色卡/世界书/预设，刷新后记住绑定，发消息自动注入对应角色卡和世界书
- **多角色卡**：PNG/JSON 格式，含内嵌"角色世界书"联动导入
- **多世界书**：可折叠、每条目独立开关
- **多预设管理**：创建/复制/重命名/删除预设，每预设独立保存角色卡+世界书+配置+记忆+关系网
- **记忆总结**：手动/自动总结对话，写入记忆并更新角色关系网
- **角色关系网**：可视化角色关系图谱
- **右上角浮动预设切换器**：一键切换当前会话的预设

## 📋 前置条件

- DeepSeek Harness (DSH) v4.1.0 或更高版本
- Web profile（`--profile web`）
- 记忆总结功能需要配置一个 OpenAI 兼容的 API（可选，不配置不影响角色卡/世界书使用）

## 🚀 安装（二选一）

```sh
# 从 npm 安装（推荐，一键安装）
dsh plugin --profile web add dsh-tavern

# 或从 GitHub 安装
dsh plugin --profile web add https://github.com/chen731215-dev/dsh-tavern
```

装完**重启 dsh web**（完全关闭后重新打开）。

## 🎮 如何使用

### 基础用法

1. 打开 DSH **「设置」→「通用设置」→「酒馆管理（原生）」** 面板。
2. **导入角色卡**：点「角色卡」的文件选择，选 PNG 或 JSON 角色卡（可多份，角色卡自带的"角色世界书"会自动一起导入）。
3. **导入世界书 / 预设**：同理可各导入多份。
4. **勾选启用**：在世界书里勾选要启用的条目。
5. 点 **「💾 保存到 Harness」**。
6. 回到 Harness，在模型/预设里选用这个预设即可开始角色扮演。

### 会话级多预设（v1.2.0+）

1. 屏幕右上角会出现 **「🎭 预设名 ▾」** 浮动按钮。
2. 点击按钮弹出预设列表，选择要绑定到当前会话的预设。
3. 每个会话可以独立绑定不同预设，切换会话自动加载对应预设。
4. 点「＋ 新建预设（复制当前）」可以基于当前预设创建新预设。
5. 发消息时会自动注入当前会话绑定预设的角色卡和世界书。

### 记忆总结

1. 在酒馆管理面板找到「🚀 手动总结」。
2. 配置记忆模块 API（OpenAI 兼容格式，如 `https://api.openai.com/v1/chat/completions`）。
3. 填写 API Key 和模型名，点保存。
4. 点「📝 立即总结」即可总结最近对话，自动写入记忆并更新关系网。
5. 可开启自动总结，每 N 楼自动总结一次。

> 面板随 DSH 深色/浅色自动换肤；切换工作区/页签时自动收起。

## 🔧 常见问题

**Q: 预设按钮不显示？**
A: 按 `Ctrl+Shift+R` 强制刷新页面。如果还不显示，检查插件是否正确安装。

**Q: 手动总结报错？**
A: 检查 API URL 是否包含 `/v1/chat/completions` 路径，模型名是否正确。插件会自动补全路径，但建议填写完整 URL。

**Q: 不同会话预设串了？**
A: v1.2.0 已实现会话级隔离，每个会话独立绑定。如果还有问题，请提 issue。
