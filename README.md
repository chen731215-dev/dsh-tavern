DeepSeek Harness (DSH) 酒馆管理插件 - 完整的角色扮演体验。

## 功能特性

### 🎭 角色卡管理
- 支持导入 SillyTavern 格式角色卡（PNG/JSON）
- 多角色卡管理，每个预设独立保存
- 角色卡自带世界书自动同步
- 一键注入当前对话

### 📚 世界书管理
- 支持导入 SillyTavern 世界书 JSON
- 卡片式可折叠 UI，按世界书分组
- 条目名称（comment）和关键词（keys）正确显示
- **智能注入**：全局条目每次注入，角色条目按关键词触发，节省 60-70% 上下文
- 注入模式切换：全文注入 / 关键词触发
- 拖放导入区域

### ⚙️ 预设管理
- 多预设管理，每个预设独立保存角色卡/世界书/记忆/关系网
- 会话级预设绑定，切换对话自动加载对应预设
- 白名单模式：只有加入白名单的会话才注入预设
- 预设删除、批量删除、全选
- 预设名称自动同步到会话名称

### 🧠 记忆模块
- 手动总结：读取最近 N 楼对话，自动写入记忆
- 自动总结：每 N 楼自动总结一次
- 预设级记忆隔离，切换预设自动加载对应记忆
- 记忆注入系统提示，AI 能看到总结内容

### 🔗 角色关系网
- 总结时自动提取角色关系
- 可视化关系图谱
- 预设级关系网隔离

### 🎬 剧情选项
- AI 每次回复输出 3 个剧情选项
- 可点击选项自动填入输入框并发送
- 自定义输入框，支持手动输入行动
- 独立开关，不依赖成人模式

### 🔞 NSFW / 成人模式
- 暴力破限注入，集成历史共识破限法
- 开启 NSFW 自动开启成人模式
- 预设词条（三人逆行等）正确注入并生效

### 🎨 AI 回复美化
- 自动识别角色卡格式（<世界>、<Status_block> 等）
- 剧情选项渲染为可点击按钮
- 编辑 AI 回复，修改后 AI 顺着改后的内容继续

### 🔒 会话隔离
- 每个会话独立保存角色卡/世界书/预设/记忆
- 切换会话自动加载对应配置
- 跨工作区会话过滤，只显示当前工作区会话

## 安装方法

### 方法一：dsh 插件市场（推荐）
1. 打开 dsh 设置 → 插件
2. 搜索 `dsh-tavern`
3. 点击安装

### 方法二：npm 安装
```bash
# 在 dsh 插件目录执行
npm install dsh-tavern
```

### 方法三：本地安装
1. 下载源码
2. 复制到 dsh 插件目录
3. 重启 dsh

## 使用说明

### 1. 基础设置
1. 打开 dsh 设置 → 酒馆管理
2. 导入角色卡（拖放或选择文件）
3. 导入世界书
4. 导入预设（如三人逆行）

### 2. 会话绑定
1. 在"当前会话预设"下拉框选择预设
2. 勾选"启用此会话的预设注入（白名单）"
3. 勾选"成人模式（强破注入）"（如需 NSFW）
4. 勾选"剧情选项"（如需 AI 输出选项）

### 3. 世界书智能注入
- 注入模式选择"关键词触发"可大幅节省上下文
- 无关键词的全局条目（世界观/规则）每次注入
- 有关键词的角色条目仅当对话命中关键词时注入

### 4. 记忆总结
- 设置总结楼数（如 20 楼）
- 点击"立即总结"或开启自动总结
- 总结内容自动写入记忆并注入系统提示

## 配置文件

- 预设根目录：`~/.dsh/.agent-presets/`
- 会话绑定：`~/.dsh/.agent-presets/session-bindings.json`
- 每个预设目录包含：
  - `agent.cordis.yml` - 角色卡
  - `characters.json` - 角色卡列表
  - `worldbooks.json` - 世界书
  - `presets.json` - 预设词条
  - `memory.md` - 记忆
  - `relations.json` - 关系网
